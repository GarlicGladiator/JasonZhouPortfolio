# Game Design Portfolio Template

A static HTML/CSS/vanilla-JS portfolio designed for GitHub Pages.

## Structure

- `index.html` — portfolio homepage
- `project.html` — reusable project/case-study page
- `style.css` — all styling
- `script.js` — small dark-mode toggle
- `assets/` — replace the placeholder images with your own work

## Getting started

1. Replace `Your Name` throughout the HTML.
2. Replace the text in `index.html` with your own portfolio content.
3. Add your images to `assets/` using these filenames, or change the filenames in the HTML:
   - `hero.jpg`
   - `project-01.jpg`
   - `project-02.jpg`
   - `project-03.jpg`
   - `project-04.jpg`
   - `blockout.jpg`
   - `final.jpg`
4. Update the social links and email address.
5. Duplicate `project.html` for each portfolio project and rename the files.
6. Push the folder to a GitHub repository.
7. In GitHub: Settings → Pages → Deploy from a branch → choose `main` and `/root`.

## Design philosophy

The visual system uses:
- parchment / warm neutral backgrounds
- ink-like dark neutrals
- restrained gold accents
- circular framing and landscape-inspired decoration
- serif display typography paired with a clean sans-serif
- generous writing areas so the portfolio emphasizes design thinking rather than artwork

The East Asian influence is intentionally expressed through layout, framing,
brush/ink-inspired decoration, spacing, and restrained motifs rather than making
the projects themselves look specifically Asian-themed.

## Image recommendation

For your actual portfolio, prioritize:
- top-down level maps
- greybox/blockouts
- flow diagrams
- annotated screenshots
- before/after iterations
- world maps
- gameplay diagrams
- small environment screenshots

Keep decorative artwork secondary so the design work remains the focus.
